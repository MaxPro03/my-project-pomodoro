# Orange

The mascot.

- `Orange3D` — voxel orange in three.js with a face, arms and legs, lit Cube World style (per-voxel ambient occlusion, sky/ground light, soft shadow); props `palette`, `pose` (stand | run | computer | read | work | sit | cheer | lie), `expression` (open | sleep | happy), `pace` (animation speed multiplier)
- `OrangeBasket` — crates of 4 oranges with the landing animation
- `ORANGE`, `PALETTES`, `paletteForProgress` — 14x14 pixel sprite and its palettes (unripe → ripe, ghost)
